# SIGES - Sistema de Gestão de Etapas de Serviços

Repositório estruturado para o projeto **SIGES**, um sistema de gestão de etapas de serviços.

## Estrutura do Repositório

* **`backend/`**: Destinado a conter o código do backend da aplicação (ex: FastAPI ou Django).
  * **`backend/app/`**: Diretório principal do código da aplicação backend.
    * **`backend/app/routers/`**: Subdiretório para organização de rotas/endpoints da API.
* **`frontend/`**: Destinado a conter os arquivos estáticos e lógicas de interface do cliente (HTML, CSS e JavaScript Vanilla).

*Observação: As pastas contêm arquivos `.gitkeep` temporários apenas para fins de manutenção da estrutura no controle de versão Git.*

## Como Inicializar

1. **Backend:**
   * Configure seu ambiente virtual de desenvolvimento Python dentro de `backend/`.
   * Crie o arquivo `requirements.txt` com as dependências necessárias e instale-as.
   
2. **Frontend:**
   * Crie seus arquivos HTML, CSS e JS dentro do diretório `frontend/`.
